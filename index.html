Selected architecture projects

Complex problems, delivered

01

Enterprise container platform re-platforming for 11 banking applications

Red Hat OpenShift → Alauda Container Platform · Absa

Eleven business-critical applications (internet and mobile banking, digital wallet, onboarding, card tokenisation, fraud detection, teller, workflow and payment aggregation) had to move platforms without customer impact, while ingress, API management, registry and logging were also reaching end of support.

  • Designed the target architecture and migration waves; mobilised and led the engineering team from inventory through cutover and handover.
  • Replaced OpenShift Routes with Gateway API (HTTPRoute, TLSRoute, TCPRoute); replaced 3scale and RHSSO with Kong and Envoy Gateway; moved registries to JFrog Artifactory with Xray scanning; upgraded Elastic Stack to 8.x.
  • Solved TLS trust-chain, CoreDNS, scheduling, session-persistence and gateway-timeout problems; validated with performance and stress tests and CSO security assurance (penetration testing, kube-bench).
  • Used LLMs to map OpenShift constructs to Alauda and draft migration artefacts, with every output expert-reviewed and tested.

All 11 applications migrated; OpenShift 3 and 4 environments decommissioned; reusable migration playbooks and per-application issue records handed to operations.

02

Monolith-to-microservices modernisation of banking applications

OpenShift · Kubernetes · AWS · API gateway

Monolithic banking workloads were slow to change, scaled only as a whole and were tightly coupled to core banking interfaces and shared data.

  • Defined service boundaries by business capability and moved functionality out incrementally (strangler pattern) behind an API gateway, so channels kept working throughout.
  • Designed API-led integration to core banking and surrounding systems, externalised configuration and session state, and gave each service its own CI/CD pipeline and GitOps deployment.
  • Managed the hard parts: shared-database coupling, transaction integrity with the core, session persistence, service-to-service TLS, and observability across many services.
  • Supported African country teams in containerising and migrating their applications onto the shared platform.

Independently deployable, horizontally scalable services with standard pipelines, security controls and monitoring.

03

Internet and mobile banking platform upgrade

OpenShift 3 → OpenShift 4 · GitOps

The bank's internet and mobile banking applications ran on an ageing OpenShift 3 estate.

  • Planned and delivered the migration to OpenShift 4 with rollback and cutover plans.
  • Introduced GitOps with ArgoCD, first for a digital-wallet application, then as the standard delivery model.

Both channels moved to OpenShift 4; GitOps adopted as the delivery standard.

04

Secure, highly available AWS and multi-cloud architecture

AWS · Azure · Terraform · Well-Architected

On-premises applications needed secure, resilient cloud hosting under banking-grade controls.

  • Architected highly available AWS solutions (VPC, EC2, EKS, Lambda, S3, RDS, CloudWatch) with Infrastructure as Code in Terraform, CloudFormation and Ansible.
  • Ran AWS Well-Architected reviews and supported migrations of on-premises applications to AWS and Azure.

Repeatable, code-defined cloud environments reviewed against the Well-Architected Framework.
